# Skill — Create Spec

Use for changes that require a specification under the resolved Change Level workflow.

## Procedure

1. Confirm declared Change Level and Risk Flags.
2. State problem and purpose.
3. Define scope and out-of-scope.
4. Define observable behavior.
5. Write falsifiable acceptance criteria.
6. Record constraints and known risks.
7. Keep implementation detail out unless required to define behavior.
8. Save under the project spec location resolved by Effective Configuration.

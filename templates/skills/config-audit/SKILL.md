# Skill — Configuration Audit

Use to convert engineering friction into evidence-based governance evolution.

## Evidence sources

- AI sessions;
- pull-request comments;
- review findings;
- defects;
- failed CI;
- human corrections;
- repeated prompts;
- rule violations;
- waiver history.

## Output

For each pattern:

- evidence;
- frequency;
- current protection;
- recommended layer;
- existing Rule ID if any;
- potential deterministic enforcement;
- lifecycle recommendation: promote, demote, scope, merge, retire, enforce, or waive.

Do not promote a speculative rule without evidence or explicit rationale.

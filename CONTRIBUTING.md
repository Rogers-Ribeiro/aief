# Contributing

## Before changing governance

1. Classify the change.
2. Governance changes are at least L2.
3. Apply the allocation test.
4. If a rule spans layers, decompose it into Intent / Binding / Parameters.
5. Keep normative Foundation technology-neutral.
6. Prefer a minimal coherent diff.
7. Report real verification evidence.

## Foundation changes

Changes under `foundation/` require explicit rationale tied to implementation or dogfooding evidence whenever possible.

A normal Stack Profile, Project Profile, or Provider Adapter need must not cause a Foundation edit.

## Generated content

Generated artifacts must be clearly distinguishable from authored content and must never be hand-edited.
